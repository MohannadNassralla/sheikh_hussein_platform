# 🌉 Sheikh Hussein Bridge Platform

An integrated web platform designed to streamline and manage passenger bookings and travel coordination services across the Jordan River Crossing (Sheikh Hussein Bridge), including transportation, hotel stays, and accommodation arrangements.

---

## 🌟 Key Features

* **🌐 Multi-Language Support:** Fully responsive user interface supporting English, Arabic, and Hebrew.
* **🏨 Hotel & Accommodation Booking:** Seamless reservation management for featured hotels (including Days Inn Amman, Siraj Amman, Mena Aqaba, and more) with automatic cost summaries and included amenities.
* **🚕 Transportation Coordination:** Flexible selection and organization of passenger transfers and vehicle types.
* **📊 Dynamic Price Calculation:** Real-time calculation of overall trip and room costs based on nights, room types, and passenger counts.
* **🔥 Real-time Database:** Secure and immediate booking storage using **Google Cloud Firestore**.

---

## 🛠️ Tech Stack

* **Frontend:** Flutter Web (Dart)
* **Backend & Database:** Firebase Cloud Firestore
* **Automation & Messaging:** Node.js (express, whatsapp-web.js)
* **Hosting:** GitHub Pages
